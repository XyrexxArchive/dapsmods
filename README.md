# DapsMods

Lightweight Android utility hub built with Kotlin, Jetpack Compose and Gradle.

- Version: 0.1.0
- Developer: xyrcodex
- Minimum Android: 6.0 (API 23)
- JDK: 17
- Music: YouTube Music search, audio stream extraction and LRCLIB lyrics.
- Tools: Facebook downloader using the getfvido.com endpoint.
- Themes: Light, Dark (default), Liquid Glass and Brutalism.

Open in Android Studio with JDK 17 and Android SDK 35. Build using the Gradle Android build task: `assembleDebug`.

APK output: `app/build/outputs/apk/debug/app-debug.apk`.

Online services may change endpoints, authentication requirements, or rate limits.
